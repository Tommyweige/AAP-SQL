# Research assets

These files support the BIRD Dev `dev_20240627` experiment: 1,534 questions,
11 databases, and 798 indexed columns.

| File | Role |
|---|---|
| `column_mapping.json` | Basic column-description index |
| `column_mapping_csv_enriched.json` | Descriptions augmented with BIRD metadata/value hints; default research index |
| `thesis_results.json` | Published thesis experiment tables, source metadata and PDF checksum |
| `thesis_relation_validation.json` | Observed numeric recovery, new-edge usage and omission ledger |

Both mappings are JSON lists of `{db_id, full_name, description}`. `full_name`
uses `table.column`; `db_id` restricts recalled candidates to the active database.
The BIRD schema/metadata provide the database and column identities; enriched
descriptions supply semantic context and value hints. Training descriptions cover
the Train databases and are prepared separately.

The online relation graph is generated by
[`build_relation_graph.py`](../../scripts/research/build_relation_graph.py) and
written under `outputs/research/thesis/`. The bundled validation file records
its observed statistics and named relations. [Reproduction steps](../../docs/research-reproduction.md).
